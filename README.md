# Esports Club English Game

A personal, non-commercial hobby project: a browser game for practising English by managing an esports club.

Data: team and player facts for League of Legends leagues are collected once from Liquipedia through its official API, with rate limits and caching. Liquipedia content is licensed under CC-BY-SA 3.0 and the game credits Liquipedia as the source.

Contact: open an issue in this repository.
